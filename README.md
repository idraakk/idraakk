## 🌟 Highlight Projects

### 🧬 Rust for Machine Learning

**🔹 [RustNet_library](https://github.com/idraakk/RustNet_library)**  
*A tiny, fast neural network engine in Rust with first‑class Python bindings.*

- From‑scratch fully‑connected neural network written in **Rust**.
- Exposed to **Python** via **PyO3** and **maturin**, combining native performance with a Pythonic API.
- Includes example datasets (e.g. *diabetes*), CLI workflows, and helper scripts for training & visualization.
- Great for understanding ML internals while staying production‑minded.

---

### 🤖 Applied AI & LLMs

**🔹 [CognifyAI](https://github.com/idraakk/CognifyAI)** – *AI‑Powered Learning Companion*  
Transforms lecture videos into an interactive Q&A experience.

- Extracts **spoken captions** and **on‑screen text** from lecture videos.
- Builds a **searchable knowledge base** from the content.
- Uses an **LLM** to answer user questions with context‑aware responses.
- Designed as a structural blueprint for intelligent study tools.

**🔹 [Search-Summarize_AI_Assistant](https://github.com/idraakk/Search-Summarize_AI_Assistant)**  
An AI agent that searches the web and summarizes results using **LangChain** and **OpenAI**.

- Real‑time web search via **DuckDuckGo** and automated summarization.
- Uses **prompt templates** and **LangChain** pipelines for flexible summarization.
- Focused on building **research copilots** for fast, high‑signal insights.

**🔹 [Digit_Recognition_ANN](https://github.com/idraakk/Digit_Recognition_ANN)**  
Handwritten digit recognition using a **Multilayer Perceptron** on the **MNIST** dataset.

- End‑to‑end pipeline: preprocessing → model architecture → training → evaluation → visualization.
- Great example of taking a classic ML problem from idea to implementation.

**🔹 [HateSpeechDetection-English](https://github.com/idraakk/HateSpeechDetection-English)**  
Logistic regression model to detect hate speech in English.

- Uses classic NLP preprocessing and ML for **binary text classification**.
- Includes training and evaluation flows, alongside Colab‑friendly notebooks.

**🔹 [Sms-Spam-Detection](https://github.com/idraakk/Sms-Spam-Detection)**  
End‑to‑end SMS spam detection with a web interface.

- Full pipeline from **data preprocessing** and **model training** to a **Flask‑based web app**.
- Exposes a simple UI for real‑time spam/ham classification.

### 🏗️ Backend, Web & Systems

**🔹 [BrandFluence / AdfluenceFlow](https://github.com/idraakk/BrandFluence)**  
*Influencer Engagement and Sponsorship Coordination Platform*  
Built as part of the **Modern Application Development** course at **IIT Madras**.

- Connects **sponsors and influencers** for campaigns and collaborations.
- Features: campaign creation/management, two‑way requests & negotiation, dummy payments, PDF/CSV transaction reports.
- Implements **role‑based access control** for auth & authorization.
- Includes **RESTful APIs** for each model in the database.  
- Stack: **Flask**, **Tailwind CSS**, REST APIs, CSV/PDF reporting.

**🔹 [E-commerce-backend-API](https://github.com/idraakk/E-commerce-backend-API)**  
E‑commerce backend using **Java Spring Boot**.

- Implements RESTful APIs for **product browsing, cart management, order placement, and purchase tracking**.
- MySQL schema design for typical e‑commerce workflows.
- Focus on clean separation of concerns and scalable backend design.

**🔹 [DevDiaries](https://github.com/idraakk/DevDiaries)**  
A full‑stack personal blogging platform.

- Built with **Flask**, **Bootstrap**, and **Flask SQLAlchemy**.
- Designed as a personal dev blog with templating, routing, and DB‑backed posts.

**🔹 [MatchMakingPlatform_Cpp_Sem2Proj](https://github.com/idraakk/MatchMakingPlatform_Cpp_Sem2Proj)**  
C++ project reflecting core data structures and OOP.

- Explores matching logic and systems design using **C++**.
- Reinforces strong CS fundamentals alongside higher‑level ML work.

**🔹 [MiniCompiler](https://github.com/idraakk/MiniCompiler)**  
A mini programming language compiler in **C++**.

- Supports variable assignments, arithmetic, control flow via loops, and printing.
- Includes custom **Lexer**, **Parser**, **Interpreter**, and basic data structures.
- Demonstrates a solid grasp of parsing, tokenization, and runtime design.
